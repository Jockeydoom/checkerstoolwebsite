03 / DOCUMENTATION✦

Everything you need to get started.

Getting started

  1. Install the approved Windows setup package.
  2. Launch Checker’s Tool and register your Windows account.
  3. Open your authorized project workspace.
  4. Refresh source files and review checking results.

Support tickets

  1. Open Support Tickets inside the app.
  2. Create a ticket with the issue details.
  3. Track replies and ticket status.
  4. Use the notification bell for updates.

Application updates

  1. Use the app's configured GitHub update checker.
  2. Review the newer release prompt.
  3. Allow installer download and checksum verification.
  4. Close the app to complete installation and restart.

Administrator dashboard

Authorized administrators can access the dashboard after Supabase authentication and Edge Function deployment.
