THE DEVELOPER STORY

Built by an engineer.
For engineers.

Nivin VarkeyPiping Engineering & Workflow Automation · UAEView developer portfolio ↗

“Engineering software should remove repetitive work, not create more of it.”

Checker’s Tool started with a familiar engineering problem: important information was spread across JDE exports, spool drawings, large network folders and project reference files. Every manual lookup took time away from checking.

With 8+ years of experience in piping engineering, fabrication and spooling, developer Nivin Varkey began using Python and workflow automation to solve these everyday challenges. The idea evolved into a desktop application that connects spool search, JDE details, local PDF indexing and project specifications.

Checker’s Tool continues to develop through practical user feedback. The goal is not simply to digitize forms but to make drawing verification and engineering coordination more reliable and efficient.

The development approach combines field experience with Python, PySide6, Excel/VBA, SQL, SharePoint, Power Automate and Supabase.

ONLY WHAT YOU NEED

Quick User Guide

Short instructions for daily tasks, without outdated workflows or database details.

Getting started
  1. Open Checker’s Tool and sign in.
  2. Select the applicable job.
  3. Open the module you need.
Search a spool or Line ID
  1. Search by spool, barcode or Line ID in JDE Search.
  2. Select the correct matching row.
  3. Review status, Hold Code and drawing details.
Open spool PDFs
  1. Search the required spool in your job.
  2. Open its matching PDF.
  3. Refresh the local index if results are out of date.
GO-BY & Instructions
  1. Select the relevant JDE result.
  2. Click GO-BY / Instructions.
  3. Read the matching spec and project notes; use zoom/maximize as needed.
My Spools
  1. Open My Spools.
  2. Review assigned records, status and aging.
  3. Use filters to find outstanding work.
Report an issue
  1. Open Support Tickets.
  2. Describe the problem and affected job or spool.
  3. Submit the ticket.
My Profile
  1. Open My Profile.
  2. Update available display details.
  3. Save.
Administrator tasks
  1. Use Admin Center → Projects for supported job configuration.
  2. Use GO-BY settings to manage reference paths and instructions.
  3. Manage users and other settings in their designated sections.

Some actions depend on the installed version and the user's permissions.
