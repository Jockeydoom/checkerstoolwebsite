User guides

Getting started

  1. Install using the provided per-user setup file.
  2. Open Checker’s Tool and complete registration.
  3. Choose Job 01414 or Job 01958.
  4. Refresh source data and review results.

Support tickets

  1. Open Support Tickets.
  2. Describe the issue and attach relevant context if supported.
  3. Track replies and status in the ticket view.
  4. Open the bell for unread ticket notifications.

Automatic updates

  1. Keep the app connected to the configured GitHub repository.
  2. Approve the update prompt.
  3. Wait for verified installer download.
  4. The application closes, installs, and restarts.

Developer details

Technology: Python, PySide6, Supabase/PostgreSQL, GitHub Releases, PyInstaller, Inno Setup.

Release process: Run tests → build one-file EXE → build Inno Setup installer → generate SHA-256 → publish both installer and checksum to GitHub Releases.

Update configuration: Central Supabase github_update settings must specify an enabled repository. The release tag must be newer than the installed version.

Security: The update client rejects downloads without a matching published SHA-256. For stronger authenticity, protect GitHub release permissions and consider code signing.

Support & troubleshooting

Use the built-in Support Tickets module to report application issues. For update failures, inspect %TEMP%\CheckersTool-Update.log. For notifications, open the bell to view connection and registration errors.
