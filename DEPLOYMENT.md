# Checker’s Tool website — V1.0.65

This website is restyled from the user-provided professionals-cv-main reference.

## Deploy
1. Upload all files in this folder (not the containing folder) to the document root of checkerstool.professionals-cv.in.
2. Verify HTTPS and the home page.
3. Open dashboard.html and configure Supabase as documented in the integrated application package.
4. Do not put a service key or other private credential into any website file.
5. Confirm administrator login, allowlist and Edge Function authorization before enabling the dashboard.
6. Link GitHub release downloads only after the actual repository and signed-off installer assets are verified.

## Status
The landing page is static and ready to upload. The dashboard remains dependent on external Supabase configuration and deployment. No changes to the Windows application are included in this website-only package.
